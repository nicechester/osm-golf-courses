# OSM Golf Course Mirror

Static GeoJSON of golf courses extracted from OpenStreetMap.

## Data

- `golf-courses-na.geojson` - North America

## Source

[Geofabrik](https://download.geofabrik.de/) extracts, updated every 6 hours via GitHub Actions.

## Usage

```
https://raw.githubusercontent.com/YOUR_USERNAME/osm-mirror/main/golf-courses-na.geojson
```
